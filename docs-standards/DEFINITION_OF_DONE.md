# Definition of Done

- Alle Prüfungen aus PRODUCT_QUALITY_STANDARD.md sind gelaufen und grün.
- Änderungen sind auf main gepusht; GitHub Pages liefert den neuen Stand.
- Verkaufsartefakte (dist/XRechnung-Batch-Pro.zip) sind bei Versionsänderung auf
  Polar und Gumroad ersetzt.
- Sichtbare Änderungen sind mit Vorher-Nachher-Screenshots belegt.
- Ein grüner Build allein ist kein visueller Qualitätsnachweis.
