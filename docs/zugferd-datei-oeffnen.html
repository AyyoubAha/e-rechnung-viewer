Warum das XML zählt – nicht das PDF-Bild

Bei ZUGFeRD-Profilen ab EN 16931 ist der strukturierte XML-Teil der maßgebliche Rechnungsinhalt. Automatische Verarbeitung, Prüfung und Archivierung laufen über diese Daten. Enthält das XML eine andere IBAN oder andere Beträge als das PDF-Bild (Fehler oder Manipulation), fällt das nur auf, wenn man das XML sichtbar macht. Der Viewer weist zusätzlich auf fehlende Pflichtangaben und unstimmige Summen hin.

Aufbewahrung: Bewahren Sie die Original-PDF-Datei unverändert elektronisch auf (GoBD) – sie enthält das maßgebliche XML.

ZUGFeRD, Factur-X, XRechnung – kurz sortiert

ZUGFeRD/Factur-X: PDF mit eingebettetem XML (hybrid). XRechnung: reine XML-Datei, Standard für Rechnungen an deutsche Behörden. Beide erfüllen die E-Rechnungspflicht; beide liest der Viewer. Reine XML-Rechnungen lassen sich hier in ein lesbares PDF umwandeln.

Selbst ZUGFeRD-Rechnungen schreiben?

Einzelne Rechnungen erstellen Sie kostenlos per Formular — wahlweise als XRechnung-XML oder direkt als ZUGFeRD-PDF (PDF/A-3, EN 16931). Viele auf einmal aus Excel erzeugt XRechnung Batch Pro (offline, 39 € einmalig).
