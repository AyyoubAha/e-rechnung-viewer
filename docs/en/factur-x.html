Factur-X: the invoice inside the PDF

A Factur-X invoice (known as ZUGFeRD in Germany) looks like a normal PDF — but the real invoice travels inside it as an embedded XML data file that accounting software reads. Here is how to see what's actually in there, and why you should.

  1. Open the free e-invoice viewer (no sign-up, runs in your browser)
  2. Drop the Factur-X / ZUGFeRD PDF — the viewer extracts the embedded factur-x.xml and shows the structured data: amounts, line items, IBAN, due date
  3. Optionally run the official-rules validation and print the report

Factur-X, ZUGFeRD, XRechnung, Peppol — quick map

Factur-X / ZUGFeRD 2.x: hybrid PDF + embedded CII XML (identical Franco-German standard). XRechnung: pure XML, required by German public authorities. Peppol BIS Billing: UBL XML used across the EU network. All of them implement the European semantic standard EN 16931 — and all of them can be opened with the viewer on this site.

Why check the embedded XML?

For profiles at EN 16931 level the XML is the authoritative content: automated payment, approval and archiving processes consume the data, not the PDF image. A mismatch between the visible PDF and the embedded data — whether a generator bug or manipulation — only becomes visible when you actually look at the XML. The viewer also flags missing mandatory fields and inconsistent totals.

Retention: Keep the original PDF file unchanged in your records — it contains the authoritative XML. A printout is not a substitute.
